# PDF Studio PRO (PDF 올인원 스튜디오)

순수 프론트엔드(**HTML, CSS, Vanilla JS**) 기술로 제작된 고성능 브라우저 기반 PDF 병합 및 문서 변환 웹 애플리케이션입니다.  
모든 작업은 사용자의 브라우저 메모리 상에서 안전하게 처리되며, 서버로 파일이 일체 전송되지 않습니다 (100% 온디바이스 개인정보 보호).

---

## 🌟 주요 기능

### 1. 여러 PDF 파일 하나로 병합하기 (PDF Merger)
- **드래그 앤 드롭 및 파일 다중 선택**: 여러 PDF 파일을 한꺼번에 선택하거나 추가로 계속 끌어다 놓을 수 있습니다.
- **✨ 상단 병합 순서 흐름도 (Sequence Flow Strip)**:
  - 사용자가 업로드한 파일들이 합쳐지는 순서를 상단 리본 스트립에서 실시간으로 한눈에 볼 수 있습니다. (`[1] 문서A (3p)` ➔ `[2] 문서B (5p)` ➔ `[3] 문서C (2p)`)
  - 각 노드를 클릭하면 해당 파일 카드로 부드럽게 스크롤 이동합니다.
- **자유로운 순서 정렬**:
  - 마우스 드래그 앤 드롭으로 카드 순서 변경
  - 각 카드별 `▲`(위로 이동), `▼`(아래로 이동) 원클릭 버튼 제공
  - A-Z 이름순 정렬, Z-A 역순 정렬, 순서 반전 기능 제공
- **페이지별 첫 페이지 썸네일 자동 생성**: PDF.js를 통해 첫 페이지의 고해상도 썸네일과 총 페이지 수를 즉시 시각화합니다.
- **문서 미리보기 모달**: 병합 전 각 문서의 내용을 페이지별로 넘겨보며 확인할 수 있습니다.
- **병합 부가 옵션**:
  - 출력 파일명 지정 (기본: `merged_document.pdf`)
  - 하단 중앙 페이지 번호(1/N) 자동 매기기 옵션
- **즉시 다운로드 및 새 탭 미리보기**: 무손실 고속 결합 후 파일 크기 및 페이지 수를 확인하고 즉시 다운로드할 수 있습니다.

### 2. PDF를 Word(.docx) 또는 PowerPoint(.pptx)로 변환
- **PDF ➔ Word 문서 (.docx)**:
  - **스마트 텍스트 & 서식 모드**: PDF 텍스트 및 단락 구조를 지능적으로 분석하여 편집 가능한 워드 문서로 변환.
  - **고해상도 페이지 레이아웃 모드**: PDF 각 페이지를 고화질 렌더링하여 워드 페이지에 원본 서식 그대로 1:1 삽입.
- **PDF ➔ PowerPoint 프레젠테이션 (.pptx) (✨ 세부정보 기반 재수정 기능 탑재)**:
  - **세부정보 기반 완전 재수정 모드 (추천)**:
    - PDF 내의 글자, 위치(X·Y 좌표), 글꼴 크기, 굵기를 분석하여 파워포인트에서 직접 클릭하고 타이핑·수정할 수 있는 **실제 네이티브 텍스트 상자(Text Box)**로 1:1 변환합니다.
    - 파워포인트에서 슬라이드를 열었을 때 글자를 지우고 새 내용을 입력하거나 폰트 크기/색상을 자유롭게 재수정할 수 있습니다.
  - **원본 디자인 배경 유지 + 편집 텍스트 오버레이 모드**:
    - 원본 PDF의 로고, 도형, 배경 그래픽을 유지하면서, 그 위에 모든 텍스트를 편집 가능한 텍스트 상자로 정확하게 얹어 디자인과 수정 편의성을 모두 확보합니다.
  - **지능형 문맥 단락 자동 결합 (Smart Clustering)**:
    - 낱개로 쪼개진 단어들을 하나의 문장/문단 단위로 자동 결합하여 수정 시 텍스트 상자가 파편화되는 현상을 방지합니다.
  - **사용자 맞춤 옵션**: 기본 글꼴 선택(맑은 고딕, Pretendard, Arial, Calibri, 나눔고딕), 화면비(16:9 와이드, 4:3, A4), 발표자 노트 자동 삽입 지원.
- **실시간 진행률 표시**: 변환 진행 상태(0% ~ 100%) 및 단계별 메시지 실시간 확인.

## 🚀 실행 방법

### 방법 1 (가장 간단한 방법)
폴더 내의 [`index.html`](file:///c:/Users/bosun/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%A8%20%EC%9E%90%EB%A3%8C/pdf%20%EB%B3%80%ED%99%98%EA%B8%B0/index.html) 파일을 더블 클릭하거나 [`실행하기.bat`](file:///c:/Users/bosun/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%A8%20%EC%9E%90%EB%A3%8C/pdf%20%EB%B3%80%ED%99%98%EA%B8%B0/%EC%8B%A4%ED%96%89%ED%95%98%EA%B8%B0.bat)을 실행하면 기본 브라우저(Chrome, Edge 등)에서 바로 열립니다.

### 방법 2 (로컬 웹 서버)
PowerShell에서 아래 명령어를 실행하여 웹 서버로 구동할 수도 있습니다:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 5500
```
이후 브라우저에서 `http://localhost:5500`으로 접속합니다.
